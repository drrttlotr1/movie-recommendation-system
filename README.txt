# Movie Recommendation System

## 📌 Project Overview

This project focuses on building a **movie recommendation system** using the MovieLens dataset.

The goal of the project is to analyze user ratings and movie metadata and use this information to develop a recommendation approach capable of identifying movies that may be relevant to a particular user.

The project covers data preprocessing, exploratory data analysis, collaborative filtering concepts, and recommendation model evaluation.

## 🗂️ Dataset

The project uses the **MovieLens ml-latest-small** dataset.

It contains:

* **9,742 movies**
* **610 users**
* **100,836 ratings**
* **3,683 user-generated tags**

The dataset includes information about movie titles, genres, user ratings, tags, and external movie identifiers.

### Main files

* `movies.csv` — movie titles and genres
* `ratings.csv` — user ratings
* `tags.csv` — user-generated movie tags
* `links.csv` — links to external movie databases

## 🔍 Project Workflow

### 1. Data Loading and Exploration

The datasets were loaded and analyzed to understand their structure, distributions, and relationships between users, movies, ratings, and genres.

### 2. Data Preprocessing

The data was prepared for further analysis and recommendation modeling, including working with user–movie rating relationships.

### 3. Exploratory Data Analysis

The analysis focuses on:

* Distribution of movie ratings
* User rating activity
* Most-rated movies
* Movie popularity
* Genre distribution
* Relationships between ratings and movie characteristics

### 4. Recommendation System

A recommendation approach was developed based on the available user-rating data.

The project explores how user preferences can be used to identify potentially relevant movies.
